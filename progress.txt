data (main data folder in root of server)
	articles (folder)
		slug num (folder)
			data.json (stores the author, desc, title, and views)
	channels (folder)
		channel name (folder) (or assign an id to each channel when created or if it doesn't have one and use the id as the folder name)
			messages.json (stores all message data for this channel)
			cache.json (stores all pending edits, deletes, reacts, username changes that need a bit to go through)
			misc.json (stores the read/write data, channel name if ids are used, the typing data, the pinned messages, the discord channel map, etc)
			attachments.json (stores the attachment urls just like the current attachments.json for this channel)
	donations (folder)
		data.json (stores the donation data)
	private (folder)
		chat id (each private chat will have an id assigned to it and used as the folder name) (folder)
			metadata.json (the metadata for each user in this private chat including lastread and unreadcount and lastmessagetime)
			messages.json (the messages between the two users in this private chat)
			misc.json (any other data of the private chat like attachments)
	notes (folder)
		data.json (stores the data for the notes)
	partners (folder)
		partner id (folder) (each partner will be assigned an id which will be the name of the folder)
			data.json (will store the data for the partner including the user id that has it, the name, the desc, the link, and the photo)
	notifications (folder)
		user id (folder)
			tokens.json (will store the user's pushtokens for notifications)
			settings.json (will store the user's settings for notifications)
	restrictedwords (folder)
		data.json (will store the restricted words)
	users (folder)
		user id (folder)
			profile (folder)
				roles.json (will store the user's roles) the roles are: isOwner, isTester, isCoOwner, isHAdmin, isAdmin, isDev, isUploader, premuim3, premium2, premium1, milestone, isPartner, verified, isSus, isDonater, isGuesser, isLink, blocksi, guardian, lanschool,linewize, secure, FortiGuard, lightspeed, cisco, contentkeeper, deledao, iboss, barracuda, and isUploader
				data.json (will store the other data of the user including the bio, dUsername, displayName, pic, uploads, votes, subbed, and online)
			settings (folder)
				data.json (will store the user's color, showMentions, theme preferences, betterWeather, etc)
	games (folder)
		games.json (will have the existing games.json logic)
		hidden.json (the hidden games will go here now)
	movies (folder)
		apply (folder)
			apply.json (will be where the apply data is stored now)
			movieaccepts (folder)
				the json files for pending movie accepts will now go here
			applychunks (folder)
				existing logic for applicant chunks will go here if there is any logic
			uploads_temp (folder)
				existing uploads temp logic will go here
			applicants (folder)
				existing applicant logic will go here
		accepted (folder)
			movies.json will be here now
			subtitles (folder)
				subtitles will go here
			movies (folder)
				movie files will go here
	logs (folder)
		acclogs.json will go here now
		report.json will go here now
		archive (folder)
			archive for reports json is here now
	groups (folder)
		group id (folder)
			data.json (will store data for id, name, owner uid, members, invcode, invlink, createdat, welcomemsgid, and lastread)
			messages.json (will store message data for the group chat)
			misc.json (will store other data for the group chat like attachments)
		data.json (will store the next id)
	uploads (folder)
		using the uploadthis logis, this is where that folder is now.
	templates (folder)
		the email templates will go here now
